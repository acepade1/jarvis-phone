# 자비스 (JARVIS)

폰·태블릿에서 쓰는 음성 AI 비서. 앱(웹앱/APK) + 서버(Render)로 구성됩니다.

- 앱 주소(GitHub Pages): https://acepade1.github.io/jarvis-phone/
- 안드로이드 APK: https://github.com/acepade1/jarvis-phone/releases/latest/download/jarvis.apk

## 1. 서버를 Render에 올리기 (한 번만, 약 5분)

서버를 쓰면 **AI 키를 폰에 넣을 필요가 없습니다.** 키는 서버에만 보관됩니다.

1. 아래 버튼(링크)을 누르고 GitHub 계정으로 Render에 로그인합니다.
   **https://render.com/deploy?repo=https://github.com/acepade1/jarvis-phone**
2. 입력칸이 나오면:
   | 이름 | 넣을 값 |
   |---|---|
   | `JARVIS_PASSWORD` | 앱에 로그인할 **내 비밀번호** (직접 정함, 길게) |
   | `GEMINI_API_KEY` | https://aistudio.google.com/apikey 에서 무료 발급 (카드 불필요) |
   | `GROQ_API_KEY` | (선택) https://console.groq.com 무료. 있으면 더 빠르고, Gemini가 막힐 때 대신 답함 |
   | 나머지 | 비워 둬도 됨 |
3. **Apply** → 3~5분 기다리면 `https://jarvis-xxxx.onrender.com` 주소가 생깁니다.
4. 앱을 열고 ⚙ 설정 → **서버 주소**에 그 주소, **비밀번호**에 위 비밀번호를 넣고 `연결 · 로그인`.
   (Render 주소로 직접 앱을 열면 서버 주소는 자동으로 채워집니다.)

### 알아둘 점 (Render 무료 플랜)
- 15분 동안 아무 요청이 없으면 서버가 **잠듭니다**. 깨우는 데 30~50초 걸립니다. 앱이 켜져 있는 동안은 8분마다 서버를 깨워 둡니다.
- 서버의 파일은 재시작/재배포 때 **초기화**됩니다. 그래서 대화 기록과 기억은 **폰에 저장**합니다.
- 무료 플랜은 월 750시간입니다. 서비스 1개를 24시간 켜 두는 정도(720시간)는 가능합니다.
- 서버 IP는 DuckDuckGo가 봇으로 의심할 수 있습니다. 막히면 우회 경로(Jina)로 자동 전환합니다.

## 2. 화면
- 가운데: 자비스 HUD 원. 듣기/생각/말하기에 따라 모양과 물결이 바뀝니다.
- 아래 가운데: 자막(내가 한 말 + 자비스 답). 대화 전체는 📜 버튼에서.
- 검색·조회·영상을 할 때: 원이 왼쪽으로 비키고 **오른쪽에 작업 화면**(검색 결과, 읽는 중인 페이지, 날씨, 영상)이 나옵니다.
  설정 → "작업 화면"을 **숨기기**로 바꾸면 화면 없이 결과를 말로만 알려 줍니다.
- 원을 탭하면 말과 영상이 멈춥니다.

## 3. 설정 (⚙)
| 항목 | 설명 |
|---|---|
| 서버 주소/비밀번호 | 위 1번에서 만든 서버에 연결 |
| 폰에 직접 넣는 AI 키 | 서버를 안 쓸 때만. 키를 넣으면 종류(Gemini/Groq/ChatGPT/Claude)를 자동으로 알아보고 알아서 배정 |
| 성능 모드 | 자동(오래된 폰이면 애니메이션 끔) / 절약 / 일반 |
| 작업 화면 | 보이기 / 숨기기 |
| 대기 방식 | 음성 호출어("자비스", "헤이 자비스") 또는 박수 두 번 |
| 기본 위치 | 기본값 부산 해운대구 |
| YouTube Data API 키 (선택) | 서버 없이 쓸 때 유튜브 검색 안정화 |
| 텔레그램 | 컴퓨터↔폰 파일 전송, 원격 대화 (아래) |

## 4. 컴퓨터 → 폰 파일 전송 (텔레그램 봇, 무료)
1. 텔레그램에서 **@BotFather** 에게 `/newbot` → **토큰**을 받습니다.
2. 자비스 설정의 "텔레그램 봇 토큰"에 넣고 저장.
3. 만든 봇에게 `/id` 를 보내면 내 ID를 알려 줍니다 → 설정의 "내 텔레그램 ID"에 넣고 저장.
4. 컴퓨터 텔레그램에서 그 봇에게 파일을 보내면 폰 화면 아래에 "📥 저장" 카드가 뜨고 자동 저장을 시도합니다. (20MB까지)

## 5. 사용 예
- "해운대 맛집 검색해줘" / "오늘 뉴스 알려줘" / "내일 날씨"
- "유튜브에서 아이유 좋은날 틀어줘" → 오른쪽 작업 화면에서 재생
- "나무위키에서 해운대 찾아줘" (나무위키가 봇을 막아서 검색 결과 요약으로 대신)
- "10분 타이머", "지금 몇 시야", "배터리 얼마나 남았어"
- "내 이름은 OO이야, 기억해" (사용자가 직접 말했을 때만 저장)

## 6. 개발 (서버)
```
pip install -r requirements.txt pytest
python -m pytest server/tests -q          # 서버 자동 테스트
JARVIS_PASSWORD=... GEMINI_API_KEY=... uvicorn server.main:app --reload
```
- `server/main.py` 로그인·작업·스트리밍, `server/ai.py` AI 연결, `server/tools.py` 도구와 권한 등급(L0~L1).
- 외부 자료(검색 결과 등)는 "명령이 아님"으로 표시되고, 기억 저장/삭제는 사용자가 직접 요청했을 때만 실행됩니다. 내부 주소 접근(SSRF)은 차단됩니다.

## 7. 한계 (솔직하게)
- 검색·조회 결과를 보여 주는 것이지, 실제 웹브라우저 화면을 중계하는 것은 아닙니다. (실제 브라우저 조작은 Phase 3)
- 폰 앱을 자동으로 열거나 폰 설정을 바꾸는 건 브라우저가 막습니다. "열기" 버튼을 띄워 한 번 누르게 합니다.
- 화면을 켜 두고 충전기를 꽂아 두세요. 화면이 꺼지면 마이크가 멈춥니다.
- **실제 폰에서의 검증은 아직 하지 않았습니다.**

## APK
- 설치할 때 "출처를 알 수 없는 앱 설치 허용"이 필요할 수 있습니다.
- GitHub Actions(`.github/workflows/apk.yml`)가 자동 빌드합니다. 빌드마다 서명 키가 새로 만들어져서, 새 APK를 설치하려면 기존 앱을 지우고 다시 설치해야 합니다.
- 웹앱(Chrome 기반)을 앱 아이콘으로 여는 방식이라 인터넷과 Chrome이 필요합니다.
