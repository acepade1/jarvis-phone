# 자비스 설치 안내

## 1. 폰에서 열 수 있게 올리기 (https 필수 — 마이크 때문)
가장 간단한 무료 방법: **GitHub Pages**
1. GitHub에서 새 저장소를 만들고 `index.html`, `manifest.json`을 올립니다.
2. Settings → Pages → Branch: main → Save
3. 나온 `https://<아이디>.github.io/<저장소>/` 주소를 폰 Chrome에서 열고, 메뉴 → "홈 화면에 추가"

(Netlify Drop에 폴더를 끌어다 놓는 방법도 됩니다.)
주소를 남에게 알려 주지 마세요. 키는 폰 안에만 저장되지만, 텔레그램 ID를 넣어 두면 본인만 자비스를 조종할 수 있습니다.

## 2. 설정 (⚙)
| 항목 | 설명 |
|---|---|
| AI 종류 / API 키 | Gemini 무료 키: aistudio.google.com |
| 예비 Groq 키 | console.groq.com (무료). 위 AI가 한도/오류면 자동 전환 |
| 대기 방식 | 음성 호출어("자비스", "헤이 자비스") 또는 박수 두 번 |
| 기본 위치 | 기본값 부산 해운대구 |
| YouTube Data API 키 (선택) | 있으면 유튜브 검색이 가장 안정적. console.cloud.google.com → YouTube Data API v3 사용 설정 → 키 생성 |

## 3. 컴퓨터 → 폰 파일 전송 (텔레그램 봇, 무료)
1. 텔레그램에서 **@BotFather** 에게 `/newbot` → 이름 정하면 **토큰**을 줍니다.
2. 자비스 설정의 "텔레그램 봇 토큰"에 넣고 저장.
3. 만든 봇에게 `/id` 를 보내면 내 ID를 알려 줍니다 → 설정의 "내 텔레그램 ID"에 넣고 저장.
4. 이제 컴퓨터 텔레그램(데스크톱/웹)에서 그 봇에게 **파일을 보내면** 폰의 자비스 화면에 "📥 저장" 카드가 뜨고 자동 다운로드를 시도합니다. (막히면 카드를 눌러 저장)
5. 봇에게 **글을 보내면** 자비스가 답장합니다. 밖에서도 원격으로 대화할 수 있습니다.

제한: 봇이 받을 수 있는 파일은 **20MB까지**입니다. 큰 파일은 압축하거나 나눠 보내세요.

## 4. 사용 예
- "자비스, 내일 날씨" / "해운대 맛집 검색해줘" / "오늘 뉴스 알려줘"
- "유튜브에서 아이유 좋은날 틀어줘" → 화면에 플레이어가 뜹니다. "일시정지", "계속 재생", "영상 꺼"
- "나무위키에서 해운대 찾아줘" (나무위키는 봇을 막아서 검색 결과 요약으로 대신합니다)
- "10분 타이머", "지금 몇 시야", "배터리 얼마나 남았어"
- "카카오톡 열어줘" → 화면에 열기 버튼이 뜹니다 (한 번 눌러야 열림)
- "내 이름은 OO이야 기억해"
- 오브(둥근 빛)를 탭하면 말과 영상이 멈춥니다.

## 5. 한계 (브라우저 앱이라서)
- 폰 앱을 자동으로 열거나 폰 설정을 바꾸는 건 브라우저가 막습니다. 대신 "열기" 버튼을 띄워 한 번 누르게 합니다.
- 화면을 켜 두고 충전기를 꽂아 두세요. 화면이 꺼지면 마이크가 멈춥니다.
- 박수 모드와 음성 호출어 모드는 마이크를 번갈아 씁니다. 박수로 깨운 뒤 20초 동안 대화하고, 조용해지면 다시 잠듭니다.
- 인터넷 검색은 무료 서비스(Jina Reader, DuckDuckGo)를 거치며 분당 약 20회 제한이 있습니다.

## APK (안드로이드 앱 파일)
- 직접 받기: https://github.com/acepade1/jarvis-phone/releases/latest/download/jarvis.apk
- 설치할 때 "출처를 알 수 없는 앱 설치 허용"을 켜야 할 수 있습니다.
- GitHub Actions(`.github/workflows/apk.yml`)가 자동으로 빌드합니다. 빌드할 때마다 서명 키가 새로 만들어져서, 새 APK를 설치하려면 기존 앱을 지우고 다시 설치해야 합니다.
- 이 APK는 웹앱(Chrome 기반)을 앱 아이콘으로 여는 방식입니다. 인터넷과 Chrome이 필요합니다.
